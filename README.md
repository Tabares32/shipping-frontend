# Frontend (CRA) for Shipping App

## Deploy to Vercel (GitHub)
1. Suba esta carpeta `frontend/` a un nuevo repo en GitHub.
2. En Vercel, **New Project** → importe su repo.
3. _Framework Preset_: **Create React App**.
4. **Environment Variable**: `REACT_APP_API_URL` con el URL del backend en Render (por ejemplo: https://shipping-backend.onrender.com).
5. Build Command: `npm run build` • Output Directory: `build`.
6. Deploy.

Para desarrollo local (opcional): `npm install && npm start`.
